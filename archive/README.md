## QuartoBook/
The former Quarto "revision notes" book that used to deploy to `/revision/`. The Quarto
build has been retired (we are standardising on the MyST / Jupyter Book world, not Quarto).

Its **content is not abandoned** — the revision notes (module summaries,
`multiple-choice-questions.md`, exam preparation, cross-cutting themes) are to be migrated
into MyST pages in the Jupyter Book 2 site. See the migration plan for details.

The `_book/` subdirectory is stale generated HTML and can be ignored/deleted.
